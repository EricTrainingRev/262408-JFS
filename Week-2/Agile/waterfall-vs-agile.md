- waterfall
    - documentation/contract heavy
    - linear
- agile
    - relationship based
    - more iterative than linear

Both are ways of working through the SDLC
- Requirements Gathering
    - what does the client want us to build?
- Design
    - how are we going to build what the client wants?
- Build
    - actually write the code to build the product
- Test
    - does the thing we built actually do what it is supposed to do?
- Deploy
    - get the app to where the user can actually use it
- Maintenance
    - make sure the app keeps working in the long run
