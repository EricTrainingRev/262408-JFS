# AI Links
Links to some AI Resources for those that would like to explore more
- [HuggingFace](https://huggingface.co)
    - THE website for accessing AI models of all stripes
    - [Gemma 4: E2B](https://huggingface.co/google/gemma-4-E2B-it)
        - an AI model designed to run on devices with minimal capabilities (think smart phone or laptop)
- [LMStudio](https://lmstudio.ai/)
    - an app for managing and running AI models. A great entry point for those that want to tinker with using AI
- [Ollama](https://ollama.com)
    - currently the fastest way to get started running AI locally.
