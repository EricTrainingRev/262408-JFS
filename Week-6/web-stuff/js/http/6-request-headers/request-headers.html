Request headers: sending metadata

Request headers are key-value pairs your browser sends with a request, giving the server context: who you are, what you want, and any credentials you're presenting. This page lets you add your own headers and prove they travel to the server — the request goes to httpbin.org/anything, which obediently echoes back the exact headers it received. The JavaScript lives in request-headers.js.

Common request headers

HeaderWhat it tells the server
HostThe domain being contacted (set automatically).
User-AgentWhat browser/OS the client is using (set automatically).
AcceptThe content types the client can handle.
AuthorizationCredentials (e.g. Bearer <token>) for logging in.
Content-TypeThe type of the request body when sending data.
