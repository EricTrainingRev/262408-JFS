HTTP headers: metadata for requests & responses

Headers are key-value pairs that travel with every request and response, carrying extra information — what the client wants, what type the body is, how to cache it, and so on. The button below sends a real request and prints the actual response headers the server sends back.

Common response headers

HeaderWhat it tells the client
ServerWhat software the server runs.
Content-TypeThe media type of the body (e.g. application/json).
Content-LengthThe size of the response body in bytes.
Set-CookieSends a cookie for the browser to store.
Cache-ControlHow (and whether) browsers/proxies may cache the response.

Common request headers

HeaderWhat it tells the server
HostThe domain name of the server being contacted.
User-AgentWhat browser/OS the client is using.
AcceptThe content types the client can handle (e.g. application/json).
AuthorizationCredentials for authenticating the client.
Content-TypeThe media type of the request body (when sending data).
