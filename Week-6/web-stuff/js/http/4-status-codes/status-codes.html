HTTP status codes: what did the server say?

Every response includes a three-digit status code that tells the client whether the request worked, got redirected, or failed. The first digit groups them by category. The cards below show the common codes; the buttons at the bottom send real requests so you can see live status codes.

2xx Success

200
OK
The request succeeded. The usual result for a successful GET.
201
Created
A new resource was created — common for a successful POST.

3xx Redirection

301
Moved Permanently
The resource's URL has permanently changed; the browser follows the new location.
304
Not Modified
Used with caching — the resource hasn't changed, so the browser can reuse its copy.

4xx Client Error

400
Bad Request
The server can't process the request because it's malformed.
401
Unauthorized
Authentication is required and is missing or wrong.
403
Forbidden
The server understood the request but refuses to let you do it.
404
Not Found
The requested resource doesn't exist on the server.

5xx Server Error

500
Internal Server Error
A generic error — the server hit an unexpected condition.
503
Service Unavailable
The server can't handle the request right now (e.g. overload or maintenance).
