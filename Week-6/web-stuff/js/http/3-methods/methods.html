What does "safe" mean?

Safe = the request never modifies the server's data. Reading a page or a post doesn't change anything, so GET and HEAD are safe. POST, PUT, PATCH, and DELETE all change or remove data, so they are unsafe.

Idempotent is a separate idea: repeating the same request multiple times has the same effect as doing it once. GET, PUT, and DELETE are idempotent — sending a DELETE twice is still just one deletion. POST is not idempotent: two identical POSTs create two separate resources, and PATCH isn't either, because each patch can build on the last.
