Promises & async/await: handling the wait

A network request is asynchronous — it takes time, and JavaScript doesn't want to freeze the whole page while waiting. A Promise is an object that stands in for a value that hasn't arrived yet. async/await is a cleaner way to write the same code. Every step here is logged in order so you can see what runs when.
