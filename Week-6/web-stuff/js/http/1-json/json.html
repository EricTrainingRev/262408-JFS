JSON: the language of APIs

JSON is the text format that almost every web API uses to send data. Over the network it is just a string. To work with it in JavaScript you convert it to a real object with JSON.parse(), and to send data to a server you convert an object back into text with JSON.stringify(). This page lets you do both. The JavaScript lives in json.js — read its comments for the details.

Why this matters for fetch: when a request comes back and you call response.json(), the browser is doing JSON.parse for you. And when you send data with fetch(url, { body: JSON.stringify(obj) }), you are using JSON.stringify to turn your object into the text the server expects.
