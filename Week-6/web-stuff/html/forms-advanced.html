Forms: the advanced controls

These build on forms.html, covering the selection and validation controls that weren't in the intro. The green/red borders come from the :valid / :invalid CSS rules in the <style> above.

1. Radio group (one choice)

Choose a size — only one is selectable because all share name="size".

This form uses method="get" — when you submit, the choice shows up in the URL as a query string, e.g. ?size=large. GET keeps the result bookmarkable.

2. Number with min/max

min/max set the allowed range; the field goes red if you go outside it.

3. File upload (requires multipart encoding)

enctype="multipart/form-data" is essential — it's how the browser sends the actual file bytes, not just the filename.

4. Multi-select (many choices)

Submits one pair per selection: skills=html&skills=css. That's the "repeated key" behavior from the note.

5. disabled vs. readonly

On submit, fixed and live values are sent; locked (disabled) is omitted from the request.

6. pattern and novalidate

pattern="[A-Za-z]{3}" means exactly three letters — the field is invalid until it matches.

This form has novalidate: the required field below is skipped by the browser (useful when JS validates instead).
