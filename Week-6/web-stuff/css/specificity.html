How specificity resolves overlap

Element + class + ID all target me. The ID wins, so I'm red.

Element + class target me. The class wins, so I'm teal.

Only the element selector targets me, so I'm grey.

Two equal classes target me. The later rule wins, so I'm green.

An inline style beats the ID selector, so I'm purple.

!important beats the inline style, so I'm purple-violet.
