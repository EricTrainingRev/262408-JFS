Positioning: placing elements relative to something

Layout systems (flex, grid) handle how elements flow. The position property moves an element to a specific spot, and can even lift it out of the flow entirely. Scroll this page to see everything.

1. static vs. relative

relative — nudged 30px down and right, but my original spot is still reserved
static — nothing special, normal flow

The red box is position: relative; top: 30px; left: 30px. Notice the empty shaded space where it would have been: relative keeps its original footprint.

2. absolute — relative to the page

absolute: 20px from the top-right of the page

This paragraph shares the stage with the absolutely-positioned box, which no longer takes up any space here.

The pink box is position: absolute; top: 20px; right: 20px. This container has no position set, so the box anchors to the page. It overlays the paragraph — it was removed from the flow.

Same absolute technique as example 2, but now the card is positioned, so the badge hugs the card's corner instead of the page. This is the classic badge/pin pattern.

4. fixed — stays while you scroll

This example's fixed nav is pinned to the bottom-right of the window. Scroll and it never moves.

I'm fixed to the bottom-right corner of the viewport. Scroll down and I stay.

position: fixed; bottom: 20px; right: 20px. Unlike absolute, fixed keys off the viewport (browser window), not any ancestor, so scrolling doesn't move it.

5. Centering

I'm centered with margin: 0 auto (a width is set)
child centered with flexbox (both axes)

Top: margin: 0 auto centers the block only horizontally, and only works with a width. Bottom: display: flex; align-items: center; justify-content: center on the parent centers the child on both axes — the modern way.
