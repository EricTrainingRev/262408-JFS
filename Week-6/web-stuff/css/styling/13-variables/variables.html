CSS variables: one value, many uses

A custom property stores a value (a color, a size, a spacing) under a name, then you reuse that name anywhere with var(). Change it in one place and every usage updates.

1. Global variables in :root

Try editing --brand in variables.css (line ~30): the button background, the accent bar, and the left border of this card all change at once — that's the whole point.

Both buttons share the same --radius and --space tokens for their shape and padding, but differ only in which color tokens they use.

2. Fallbacks, and per-element override

This card's --card-pad comes from the global token, so all cards line up.
I override --card-pad locally (scoped to me), so my padding is smaller.

The second card declares its own --card-pad: 8px on itself — variables cascade like any property, so the closest definition wins. And var(--missing, fallback) shows how a default kicks in when a variable isn't defined.
